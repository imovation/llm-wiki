# 三层架构

LLM Wiki 生态的共同架构骨架——Karpathy 称之为 **"三层架构"**，也是本 wiki 采用的结构。

## 三层

```
原始来源（Raw Sources）    ← 不可变原材料，LLM 只读不改
        ↓ 编译
Wiki（编译知识）           ← LLM 生成的结构化、互链页面
        ↓
Schema（模式）             ← 规则、约定、领域定义 & 工作流
```

| 层 | 内容 | 谁写 | 谁读 |
|---|---|---|---|
| Raw Sources | 文章/论文/图片/会议记录 | 人类 curate | LLM |
| Wiki | 摘要/实体页/概念页/对比 | LLM | 人类(Obsidian 浏览) |
| Schema | SCHEMA.md / AGENTS.md | 人+LLM 共同演进 | LLM |

## 关键原则

1. **raw 不可变**——纠错只能写在 wiki 页面，不能改源头（source of truth 校验不变）
2. **wiki 完全 agent-owned**——LLM 创建/更新/交叉引用/保持一致
3. **schema 是关键配置**——正是它让 LLM 成为"有纪律的 wiki 维护者"而非自定义 chatbot，随领域探索不断演进

## 在本 wiki 的实现

- raw/ = 源文档 + 历史会话导出
- SCHEMA = [[SCHEMA]]（页面即仓库根 SCHEMA.md）
- entities/ concepts/ comparisons/ queries/ = wiki 层
- index.md / log.md = 导航 + 台账
